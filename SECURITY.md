# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Use GitHub's private
"Report a vulnerability" button on the Security tab of this repository, and include steps to reproduce.
You can expect an acknowledgement within a few days.

## What is covered

Authentication and sessions, authorisation, input handling, and the security headers are described in the
[Security section of the README](README.md#security), and each defence listed there has an automated test.

## Supported versions

Only the latest release on `main` receives security fixes.
